# v1.1.9

Supply-chain security hardening for the POSIX installer: pins SHA-256 digests
for downloaded VapourSynth API3 headers and pins the NNEDI3CL repository
checkout to a reviewed commit SHA.

______________________________________________________________________

## 🔍 What's in this release

- **Pinned VapourSynth API3 headers**: `install.sh` verifies SHA-256 digests
  for `VapourSynth.h` and `VSHelper.h` prior to compiling NNEDI3CL, refusing
  compilation on mismatch (parity with `HAVSFUNC_EXPECTED_SHA256`).
- **Pinned NNEDI3CL commit**: `install.sh` checkouts reviewed commit SHA
  `eb2a810c0b7dfdd3ad908a1bdc07d6daab64eb57` (release tag `r8`).
- **Test coverage**: `tests/unit/test_runtime_helpers.py` tests both valid and
  mismatched header digests, commit validation, and VapourSynth version gates.
- **Version 1.1.9** in `pyproject.toml`, `sonar-project.properties` and
  `AGENTS.md`.

## 🧪 Validation

- Full local CI-parity pipeline passes: linters, Pylint 10.00/10, Radon grade
  A, all tests passing, and >=90% line coverage per-file and repository-wide.
