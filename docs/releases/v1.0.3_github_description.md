# Auto-VHS-Deinterlacer v1.0.3 — Stronger Validation, Security Hardening & Safety Fixes

This release tightens quality gates across both CI and the local pipeline,
hardens runtime safety paths, and expands test coverage around edge and failure
scenarios.

______________________________________________________________________

## 🔍 What's in this release

- **Strict style and supply-chain checks added to CI and the local workflow**:
  Black formatting check, Taplo TOML lint, Bandit security scan, and pip-audit
  dependency scan — all enforced without suppression comments.
- **Hardened XML parsing** in coverage scripts: replaced the stdlib XML parser
  with `defusedxml` to eliminate XXE exposure.
- **Pipeline and runtime safety improvements**:
  - More robust pipeline process-result evaluation.
  - Safer timestamp formatting to avoid format-string edge cases.
  - More reliable Windows binary-mode handling for native `vspipe` output.
  - Stable DLL directory handle retention across runtime paths.
- **Expanded test coverage** around native patching helpers, pipeline branching,
  execution summaries, and error-handling paths.

## 🧪 Validation

- Full local pipeline passes end-to-end.
- All linters, security scanners, and formatters pass without suppressions.
- Current full-suite result: all tests pass, coverage gate ≥ 90%.
