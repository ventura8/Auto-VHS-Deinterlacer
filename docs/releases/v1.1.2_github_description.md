# Auto-VHS-Deinterlacer v1.1.2 — macOS FFmpeg Integrity & Dependency Refresh

This release closes a supply-chain gap in the macOS installer — the bundled
FFmpeg/FFprobe archives from evermeet.cx are now SHA-256 pinned and extracted
with a zip-slip guard, matching the guarantees the Windows and Linux installers
already had — and refreshes every production and CI dependency to its latest
final version, including Torch 2.14.0 / TorchVision 0.29.0 and CUDA 13.2
Update 1.

______________________________________________________________________

## 🔍 What's in this release

- **macOS FFmpeg supply-chain hardening** — `install.sh` pins the SHA-256 of
  `ffmpeg-9.0.1.zip` and `ffprobe-9.0.1.zip`, refuses to install on mismatch,
  and replaces `ZipFile.extractall()` with a guarded single-file extractor.
  The logic lives in a testable `install_darwin_ffmpeg()` function; unit tests
  assert the exact pins and execute the function against genuine, tampered,
  and zip-slip fixture archives.
- **Torch 2.13.0 → 2.14.0 (+cu132), TorchVision 0.28.0 → 0.29.0 (+cu132)** —
  2.14.0 is now a genuine PyPI final with a matching cu132 wheel, lifting the
  staging-build reservation from v1.1.1. TorchAudio stays at its final 2.11.0.
- **CUDA 13.2 Update 1** — `nvidia-cuda-runtime` and `nvidia-cuda-nvrtc`
  `→ 13.2.86`, `nvidia-cublas` `→ 13.4.1.3`, `nvidia-cudnn-cu13` `→ 9.24.0.43`
  (the version the Torch 2.14.0 wheel declares). The toolkit series stays on
  13.2 because no `cu133`/`cu134` Torch build exists yet; `pyproject.toml`
  documents the constraint inline.
- **`onnxruntime-gpu` 1.29.0 → 1.30.0** — its `cuda`/`cudnn` extras are
  satisfied by the pins above.
- **Developer tooling refreshed** — `ruff` `0.16.7`, `pymarkdownlnt` `0.9.40`.
- **Poetry 2.4.2 → 2.4.3** — synchronised across the CI workflow, both
  installers, and both local pipeline runners.
- **Already current, left unchanged** — all five GitHub Actions (SHA pins
  re-verified against upstream tags), FFmpeg 9.0.1, VapourSynth R79,
  `audio-separator` 0.47.0, `librosa` 1.0.0, and the rest of the dev toolchain.

## 🧪 Validation

- Full local pipeline passes end to end — Taplo, Bandit, pip-audit, Black, isort,
  Ruff, Flake8, Pylint (10.00/10), Radon, Markdown lint, and the complete test
  suite — with the coverage gate held at ≥ 90% per file and overall. The Darwin
  FFmpeg branch was additionally exercised against genuine, tampered, and
  zip-slip archives.
