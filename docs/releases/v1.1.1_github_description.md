# Auto-VHS-Deinterlacer v1.1.1 — Pipeline Improvements & Dependency Refresh

This release improves the restoration pipeline while refreshing every production
and CI dependency to its latest final version. It adds GPU-aware deinterlacing
and QTGMC configuration, optional-plugin handling, native frame-streaming
fallback, and runtime version reporting. The VapourSynth runtime advances to R79
and the GitHub Actions toolchain is re-pinned to current commit SHAs.

______________________________________________________________________

## 🔍 What's in this release

- **GPU-aware deinterlacing and QTGMC** — pipeline configuration selects
  compatible hardware acceleration where it is available.
- **More resilient VapourSynth execution** — optional plugins are handled safely
  and native frame streaming provides a fallback when external `vspipe` is
  unavailable.
- **Runtime version reporting** — the CLI reads and reports the project version
  from `pyproject.toml`.
- **VapourSynth R77 → R79** — bumped in `pyproject.toml`, `install.sh`, `install.ps1`,
  and `docker/Dockerfile.ubuntu`. R79 ships the same `abi3` wheel matrix as R77,
  so every supported platform is covered without a source build.
- **Audio stack refreshed** — `audio-separator` `0.44.3 → 0.47.0`,
  `onnxruntime-gpu` `1.27.0 → 1.29.0`, and `librosa` `0.11.0 → 1.0.0` (major).
- **Developer tooling refreshed** — `isort` `8.0.1 → 9.0.1` (major),
  `pylint` `4.0.8`, `ruff` `0.16.5`, `mdformat-frontmatter` `2.1.2`.
- **Poetry 2.4.1 → 2.4.2** — synchronised across the CI workflow, both installers,
  and both local pipeline runners.
- **GitHub Actions bumped and re-pinned** — `setup-python` `v6.3.0 → v7.0.0`,
  `upload-artifact` `v6.0.0 → v7.0.1`, `action-gh-release` `v3.0.2 → v3.0.3`,
  all pinned to full commit SHAs. Both majors are non-breaking for this project.
- **CUDA 13.3.1 evaluated and deliberately deferred** — `torch 2.13.0+cu132`
  is built and tested against CUDA 13.2. No `cu133` build was found on the
  checked PyTorch stable, test, or nightly wheel indexes. The CUDA pins stay on
  13.2, and `pyproject.toml` now documents the constraint inline.
- **Already current, left unchanged** — Torch 2.13.0 / TorchVision 0.28.0 /
  TorchAudio 2.11.0, FFmpeg 9.0.1, `actions/checkout` v7.0.1, and
  `actions/download-artifact` v8.0.1.

## 🧪 Validation

- Full local pipeline passes end to end — Taplo, Bandit, pip-audit, Black, isort,
  Ruff, Flake8, Pylint (10.00/10), Radon, Markdown lint, and the complete test
  suite — with the coverage gate held at ≥ 90% per file and overall.
