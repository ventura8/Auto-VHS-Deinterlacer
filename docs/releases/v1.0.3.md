# v1.0.3

## Summary

v1.0.3 strengthens validation and security quality gates across both CI and
the local pipeline, aligns runtime helper behavior for safer execution paths,
and expands test coverage around edge and failure paths.

## Highlights

- Added strict style and supply-chain checks to CI and local workflow:
  - Black check
  - Taplo TOML lint
  - Bandit security scan
  - pip-audit dependency scan
- Kept no-ignore/no-suppression policy while fixing discovered findings.
- Hardened XML parsing in coverage scripts using defusedxml.
- Improved pipeline and runtime safety handling:
  - Better pipeline process result evaluation
  - Safer timestamp formatting
  - More robust Windows binary-mode handling for native vspipe output
  - Stable DLL directory handle retention for runtime paths
- Increased coverage around native patching helpers, pipeline branching,
  execution summaries, and error handling.

## CI and Local Validation Updates

- CI workflow now runs, in order:
  - PowerShell lint
  - Taplo
  - Bandit
  - pip-audit
  - Black
  - isort
  - Ruff
  - Flake8
  - Pylint
  - Radon (complexity, maintainability, raw, halstead)
  - Markdown formatting and lint
  - Pytest with coverage
  - Per-file coverage enforcement
  - Coverage summary generation
- Local pipeline mirrors this policy with equivalent checks.

## Security and Reliability Changes

- Replaced stdlib XML parser usage in coverage scripts with defusedxml.
- Ensured Bandit medium-and-above scanning passes without suppression comments.
- Integrated pip-audit in both local and CI quality flows.

## Tests and Verification

- Added and refined tests in:
  - tests/native
  - tests/integration
  - tests/unit
- Verified full local pipeline succeeds end-to-end.

## Notes

- pip-audit may report non-PyPI package skip notices in plugin-heavy
  environments; this does not indicate a known vulnerability in audited
  packages.
