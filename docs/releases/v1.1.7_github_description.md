# v1.1.7

A security patch release. On Fedora, `install.sh` no longer enables a
third-party repository or replaces the system FFmpeg. The pipeline's product
code is unchanged.

______________________________________________________________________

## 🔍 What's in this release

- **No silent RPM Fusion install on Fedora.** The installer no longer runs
  `dnf install` as root on an unpinned `rpmfusion-free-release` URL or swaps
  the system FFmpeg with `--allowerasing`. It installs `ffms2` only from
  repositories that are already enabled. When the full FFmpeg is missing, it
  prints the manual RPM Fusion step that H.264 decoding needs.
- **Version 1.1.7** in `pyproject.toml`, `sonar-project.properties` and
  `AGENTS.md`.

## 🧪 Validation

- The full local pipeline passes: every linter, Pylint 10.00/10, Radon grade
  A, 424 tests passed, and 94% coverage, with every product file above 90%.
