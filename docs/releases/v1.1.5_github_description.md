# v1.1.5

SonarQube Cloud analysis in CI and locally with every finding fixed, followed
by a pass on real hardware (RTX 3080 on Linux, RTX 5090 on Windows) that found
and fixed defects the tests could not see. The most important: AV1 masters
encoded with NVENC carried an undefined AV1 level that libaom refused to
decode.

______________________________________________________________________

## 🔍 What's in this release

- **AV1 NVENC masters decode everywhere** — `av1_nvenc` wrote AV1 level 7.3,
  which the spec does not define, so libaom rejected the files. The level is
  now pinned to 5.1; verified on an RTX 5090 (level 13, libaom decodes every
  frame).
- **The E2E suite checks the bitstream** — outputs are fully decoded, AV1
  levels must be defined, and the AV1 test fails if NVENC hardware silently
  falls back to the CPU encoder.
- **The installers check NVENC** — both report whether AV1 will run on the
  GPU and why not (GPU without AV1 NVENC, or a driver older than 610.00).
  `install.sh` installs the missing `libnvidia-encode` library; the kernel
  driver is never touched. Set `AVD_SKIP_NVENC=1` to skip.
- **SonarQube Cloud** — CI scan with the quality gate enforced, plus a local
  scan script. All 32 findings fixed with no suppressions; the pull request
  analysis reports 0 bugs, smells, vulnerabilities and hotspots.
- **Audio sync** — a correction too small to express is now dropped:
  `atempo=1.000000` is not a no-op and trims ~1 ms of audio.
- **Tests that reach what they name** — the drift-correction test now
  exercises drift correction, and the QTGMC fallback chain runs under test
  for the first time.
- **Dependencies** — filelock 4.0.1, urllib3 2.8.0, coverage 7.16.1,
  ruff 0.16.8 and other patch updates.

## 🧪 Validation

- The full local pipeline passes: every linter, Pylint 10.00/10, Radon grade
  A, 407 tests with no skips, 95.48% line and 87.18% branch coverage (93.64%
  combined), every product file above 90%.
- Verified on real hardware, with detection enabled: RTX 3080 Laptop (Ubuntu,
  QTGMC on the GPU, drift correction, Linux installer) and RTX 5090 (Windows 11,
  AV1 NVENC encode, `install.ps1` under PowerShell 5.1 and 7.6).
