# v1.1.6

A security and quality patch release. It fixes the four issues SonarQube Cloud
reported on `main` after v1.1.5, bringing the project back to zero open
issues. The pipeline's product code is unchanged.

______________________________________________________________________

## 🔍 What's in this release

- **The Radon gate only accepts paths inside the repository.** In
  `enforce_radon_grade.py`, every target and the `--summary-out` path must
  resolve inside the working tree. Option-like targets are refused, and
  `radon` receives its targets after `--`. This fixes two command argument
  injection findings and one path traversal finding, and adds 17 new tests.
- **The macOS package builder uses `[[ ]]`.** Its conditional tests in
  `build_pkg.sh`, including the embedded app launcher, now use `[[ ]]`.
- **Version 1.1.6** in `pyproject.toml`, `sonar-project.properties` and
  `AGENTS.md`.

## 🧪 Validation

- The full local pipeline passes: every linter, Pylint 10.00/10, Radon grade
  A, 419 tests passed (5 platform-bound skips), and 95.62% line and 87.34%
  branch coverage, with every product file above 90%.
- Verified on real hardware with detection enabled: RTX 5090 on Windows 11
  (419 passed) and RTX 3080 Laptop on Ubuntu 26.04.1 (424 passed, no skips).
