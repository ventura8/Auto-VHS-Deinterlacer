# Release v1.1.7 - Fedora Installer Supply-Chain Hardening

## Security

- `install.sh` (Fedora branch of `vs_system_ffms2`): removed the automatic
  root install of `rpmfusion-free-release` from an unpinned, Fedora-versioned
  mirror URL. Errors were swallowed, so the step ran without any integrity
  check.
- Removed `dnf install --allowerasing ffmpeg-libs ffms2`, which replaced the
  host's FFmpeg stack and kept a third-party repo on the host for later
  updates.
- `ffms2` is now installed with `dnf install -y ffms2` from repositories that
  are already enabled. If `ffmpeg-libs` is absent, the installer warns that
  Fedora's `libavcodec-free` lacks H.264 decoding and points to the manual
  RPM Fusion setup plus `sudo dnf swap ffmpeg-free ffmpeg --allowerasing`.
