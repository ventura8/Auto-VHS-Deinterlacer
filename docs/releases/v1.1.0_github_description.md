# Auto-VHS-Deinterlacer v1.1.0 — Cross-Platform Support, Real E2E Tests & Dockurr Containers

This release delivers cross-platform compatibility across Windows, Linux, and macOS, alongside automated POSIX installers, real-dependency synthetic video E2E testing, Ubuntu 26.04 Docker containers, and virtualized Windows and macOS testing environments with `dockurr/windows` and `dockurr/macos`.

______________________________________________________________________

## 🌐 Cross-Platform Linux & macOS Architecture

- **Hardware Detection**: Multi-OS CPU brand resolution (`/proc/cpuinfo`, `sysctl`, Windows registry) and RAM detection (`os.sysconf`, `/proc/meminfo`, `GlobalMemoryStatusEx`).
- **Dynamic Site Packages & Plugins**: Automatic discovery of Python `site-packages` layouts and multi-platform VapourSynth plugin binaries (`.dll`, `.so`, `.dylib`).
- **POSIX Automation**: Added `install.sh` with SHA-256 verified `havsfunc.py` r33, `start.sh` launcher, and `run_pipeline_localy.sh` quality runner.
- **Architecture-Specific macOS Releases**: Dedicated Apple Silicon and Intel
  archives are packaged and clean-install verified on `macos-15` (M1) and
  `macos-15-intel` respectively.

## 🧪 Real-Dependency E2E Testing

- **Synthetic Interlaced Video Generation**: Real E2E tests generating interlaced video with audio via `ffmpeg lavfi` and validating bob-deinterlacing speed, size, and doubled frame rates (`>50 fps`).
- **Installer Test Suite**: Automated verification of installer execution, virtual environment creation, and executable permissions.

## 🐳 Docker & Virtualized Test Containers

- **Ubuntu 26.04 Environment**: `docker/Dockerfile.ubuntu` for containerized Linux testing.
- **Dockurr Windows VM**: `docker/docker-compose.windows.yml` utilizing `dockurr/windows@sha256:0cff9eb0e7aee9953e55bc682852ca4fdca233145a58ae1ec94f0b0c01a2ed30` with KVM acceleration and unattended OEM test execution.
- **Dockurr macOS VM**: `docker/docker-compose.macos.yml` utilizing `dockurr/macos@sha256:08d1bcaac74ad44d548b7ce683b3dded083512d2a0d26416f9a620b763f8ea3d` with KVM acceleration. **Warning:** Apple's macOS EULA restricts macOS virtualization to genuine Apple hardware; run this container only on Apple machines.
- **Unified Test Runner**: `docker/run_dockurr_tests.sh` to trigger containerized runs across `--ubuntu`, `--windows`, `--macos`, and `--all`.

## ⚙️ CI & Quality Gates

- Added `ubuntu_docker_e2e` and `macos_e2e` jobs in GitHub Actions CI.
- Added `workflow_dispatch` trigger for on-demand pipeline runs.

## 🧪 Validation

- All quality gates pass: Bandit, pip-audit, Black, isort, Ruff, Flake8, Pylint, Radon, and Markdown lint.
- All code maintains 100% Grade A Radon complexity (CC ≤ 5), zero suppressions, and ≥90% per-file test coverage across product code (`auto_deinterlancer.py` and `modules/`); `.github/scripts/` is validated separately via strict linters.
- Full test suite passes across Linux, macOS, and Windows test environments, including the real-dependency E2E pipeline and installer suites.
