# v1.0.4

## Summary

v1.0.4 introduces security-hardened installer downloads with SHA256 integrity
verification, fixes a critical command-injection vulnerability in the drag-and-drop
launcher, adds strict `ram_cache_mb` config validation, and hardens the VapourSynth
core settings to guarantee integer-typed values. It also expands agent tooling with a
full skills library, upgrades key dev dependencies, and aligns the local pipeline and
CI markdown linting flags.

## Highlights

- **SHA256 integrity verification for all installer downloads** — `install.ps1` now
  fetches and verifies the upstream SHA256 checksum before using the FFmpeg static build
  zip (via `www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip.sha256`).
  `havsfunc.py` is verified against a pinned hash; any mismatch deletes the download
  and aborts the install with a clear error.
- **Batch argument injection fix in `start.bat` / `install.ps1`** — the launcher
  previously forwarded drag-and-drop arguments via bare `%*`, allowing crafted filenames
  to inject arbitrary batch commands. Fixed by replacing `%*` with an explicit loop that
  quotes each positional argument with `"%~1"`. `setlocal` added to isolate the batch
  environment. Tests assert `%*` is absent and `"%~1"` is present in both files.
- **`ram_cache_mb` config validation added** — `config.py` now validates
  `manual_settings.ram_cache_mb` using the same strict parse-and-validate pattern as
  `cpu_threads`: rejects non-integers, rejects values below 128 MB, exits with a
  descriptive error. `vspipe.py` explicitly casts both settings to `int` before writing
  them into the generated VPY script to prevent type-injection from config.
- **Install error clarity**: the catch block in `install.ps1` now forwards `$_` so the
  actual exception message is included in the `[ERROR]` output line.

  suppress line-length warnings from `pymarkdown`, matching the intended CI behaviour.

  `"8192"` normalizes to integer `8192`.
- Added `test_detect_hardware_manual_profile_ram_cache_mb_invalid`: asserts multi-line
  string injection and below-minimum values both trigger `sys.exit`.
- Added `test_start_bat_script_quotes_arguments`: asserts `%*` is absent and `"%~1"` is

  landmarks are present in `install.ps1`.
