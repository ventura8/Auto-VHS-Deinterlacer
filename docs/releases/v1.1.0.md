# v1.1.0

## Summary

v1.1.0 expands Auto-VHS-Deinterlacer with comprehensive cross-platform support
across Linux (Ubuntu, Debian, Fedora, Arch) and macOS (Apple Silicon & Intel) alongside
Windows. It introduces POSIX installation and launcher automation (`install.sh`, `start.sh`),
an end-to-end (E2E) testing framework with real synthetic video deinterlacing, Ubuntu 26.04
Docker containerization, and virtualized Windows and macOS testing infrastructure using
`dockurr/windows` and `dockurr/macos`.

## Highlights

- **Cross-Platform Linux & macOS Support**:
  - Device-aware CPU brand string extraction across Linux (`/proc/cpuinfo`), macOS (`sysctl machdep.cpu.brand_string`), and Windows registry.
  - Physical RAM detection across POSIX (`os.sysconf` / `/proc/meminfo`) and Windows (`GlobalMemoryStatusEx`).
  - Dynamic virtual environment path and `site-packages` directory resolution (`lib/pythonX.Y/site-packages` vs `Lib/site-packages`).
  - Multi-platform VapourSynth plugin loading (`.dll`, `.so`, `.dylib`).
- **POSIX Automation Scripts**:
  - `install.sh`: Fully automated installer creating `.venv`, installing dependencies via Poetry, downloading `havsfunc.py` r33 with SHA-256 verification (`4da2839544b1ce9382db670b069dc358228251d147dad91f740a860840e04924`), applying patches, checking media tools (`ffmpeg`, `ffprobe`, `vspipe`), and generating `start.sh`.
  - `start.sh`: Shell launcher forwarding arguments and file paths to `.venv/bin/python auto_deinterlancer.py`.
  - `run_pipeline_localy.sh`: Local CI validation runner on POSIX systems.
- **Real-Dependency E2E Test Suite**:
  - Synthetic interlaced video generator using `ffmpeg -vf tinterlace` to test the full pipeline and verify doubled bob-deinterlacing framerates (`>50 fps`).
  - Installer artifact tests verifying permissions and execution invariants.
- **Docker & Virtualized OS Test Infrastructure**:
  - `docker/Dockerfile.ubuntu`: Containerized Ubuntu 26.04 environment with real FFmpeg and VapourSynth dependencies.
  - `docker/docker-compose.windows.yml`: QEMU/KVM virtualized Windows container powered by `dockurr/windows@sha256:0cff9eb0e7aee9953e55bc682852ca4fdca233145a58ae1ec94f0b0c01a2ed30` with unattended OEM installation automation.
  - `docker/docker-compose.macos.yml`: QEMU/KVM virtualized macOS container powered by `dockurr/macos@sha256:08d1bcaac74ad44d548b7ce683b3dded083512d2a0d26416f9a620b763f8ea3d`. **Warning:** Apple's macOS EULA restricts macOS virtualization to genuine Apple hardware; run this container only on Apple machines.
  - `docker/run_dockurr_tests.sh`: Unified multi-target test runner.
- **CI Enhancements**:
  - Added `ubuntu_docker_e2e` and `macos_e2e` jobs in `.github/workflows/ci.yml`.
  - Added `workflow_dispatch` trigger.
- **Architecture-Specific macOS Release Artifacts**:
  - Packages and verifies a dedicated Apple Silicon archive on GitHub's M1
    `macos-15` runner.
  - Keeps a separately named Intel macOS archive on `macos-15-intel`.
