# v1.0.2

## Summary

This release focuses on reliability, validation consistency, and clearer project boundaries. It tightens runtime error handling, improves edge-case safety in sync and native output paths, and aligns local/CI documentation and commands around the repository `.VENV` workflow.

## Highlights

- Improved startup failure behavior in the entrypoint by ensuring critical runtime exceptions exit with a non-zero status.
- Hardened configuration parsing for `audio_sync_offset` to route invalid values through the existing error-and-exit path.
- Added a divide-by-zero safety guard in audio drift correction when video duration is zero.
- Updated native Y4M output to fail fast on unsupported clip formats instead of silently defaulting to an assumed colorspace.
- Expanded CI coverage target to include `auto_deinterlancer.py` alongside `modules` with the existing 90% threshold.
- Updated test discovery configuration to preserve both `test_*.py` and `*_test.py` patterns.
- Replaced platform early-returns in CPU fallback tests with explicit `pytest` skip behavior.
- Moved the VapourSynth probe helper out of unit tests into a diagnostics location.

## Documentation and Workflow Updates

- Standardized setup and validation docs to use explicit local paths:
  - `.\install.ps1`
  - `.\run_pipeline_localy.ps1`
  - `.\.VENV\Scripts\python.exe` for Ruff, Flake8, Pylint, and pytest
- Removed duplicated pytest coverage flags in `run_pipeline_localy.ps1` so it relies on `pytest.ini` addopts while still targeting `tests/`.
- Updated architecture docs to explicitly document the `modules/core/patch_havsfunc.py` compatibility exception.
- Added `.VENV` to Flake8 exclusions.

## Validation

- Focused tests and full test suite pass.
- Current full-suite result: 115 passed, 1 skipped.
- Coverage gate remains green (>= 90%).
