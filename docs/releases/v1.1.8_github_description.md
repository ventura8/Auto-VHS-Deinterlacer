# v1.1.8

A quality patch release. It fixes the two minor issues SonarQube Cloud
reported on `main` after v1.1.7, bringing the project back to zero open
issues. Behaviour is unchanged.

______________________________________________________________________

## 🔍 What's in this release

- **VPY header lines are added with `list.extend()`.** In
  `modules/runtime/vspipe.py`, `_get_vpy_header` replaces consecutive
  `append()` calls with `extend()` (python:S9409).
- **One `with` statement for the VSPipe→FFmpeg pipe.** In
  `modules/runtime/pipeline.py`, `_run_encoding_pipeline` opens both processes
  in a single parenthesized `with` (python:S9154).
- **Version 1.1.8** in `pyproject.toml`, `sonar-project.properties` and
  `AGENTS.md`.

## 🧪 Validation

- The full local pipeline passes: every linter, Pylint 10.00/10, Radon grade
  A, 424 tests passed, and 94% coverage, with every product file above 90%.
